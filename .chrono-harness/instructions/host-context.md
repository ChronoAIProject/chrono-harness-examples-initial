# 首次接入宿主上下文

本仓是文档宿主，没有业务项目、脚本测试或空 CI 单元。安装、当前短命令、指南生成与 CI 生成的唯一入口见根 README。当前明确采用 macOS arm64／macos-14；产品的 Linux 安装结果不代表本宿主已完成 Linux 检查。

共享治理登记仍为 proposed，外部输入闭包未完成。新版工具通过固定发布清单采用，不覆盖本宿主的英语指南选择。先生成指南和工作流，再提交候选并运行登记的 canonical check；schema 或入口变化须同步当前使用方和 FILEMAP。

规则、CI 或稳定性迁移先在新的 integration 分支通过真实 feature PR 验证，再交付 dev。按任务授权完成推送、就绪 PR、真实合并及落地核验，无需再次确认。本仓未启用原生自动合并，现有 GitHub App 修改该设置返回 403；不申请额外权限，等待适用 CI 全部通过后，通过现有合并权限匹配当前 head 并按原保护交付。只使用已有权限；失败保留原件，独立工作继续。

首次文件清单只适用于无父事件；现有历史中的升级是普通 DELTA，不能重跑历史判官来验本轮候选。真实发布、安装、下游合并与落地检查分别验收；unknown 不算成功。
